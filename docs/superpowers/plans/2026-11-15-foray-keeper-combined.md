# Foray + Keeper Combined App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fold Keeper's CA/NV fishing rules into Foray, behind a satellite map home with a Today's trip card, and get rules working offline.

**Architecture:** Keeper's open/closed logic is pulled out into a pure, DB-free module (`keeper/src/resolve/`) that Keeper's API itself uses. Foray's `import-keeper` script copies that module into `lib/fishing/engine/`, and turns Keeper's committed JSON into a light waters index (TS) plus per-water JSON under `public/fishing/`. The service worker precaches all of it. The device resolves rules for its local date. MapLibre GL replaces Leaflet.

**Tech Stack:** Next.js 15 static export, React 19 RC, MapLibre GL 4.7, serwist, `node --test --experimental-strip-types`. Keeper side: Hono, Drizzle, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-15-foray-keeper-combined-design.md`

## Review Focus

1. **Evening date rollover.** After 4 pm Pacific, `new Date().toISOString()` is already tomorrow in UTC. The device must resolve rules for the *local* date, so a season that ends today still shows OPEN tonight. Test in Task 4.
2. **Pacific Northwest or no GPS.** With no CA/NV water within 50 mi, or no location at all, the fish half shows "No fishing data for this area yet" (or "Set a location"), never a blank list or a crash. Test in Task 9.
3. **Water JSON fails to load offline** (SW cache miss, first visit). The rules sheet shows "Rules not downloaded — connect once to save them" with a retry button, not a spinner forever. Test in Task 8.
4. **Rules that apply across waters.** Pyramid Lake's one `authority_territory` rule must apply to every water linked to that authority by name, the way Keeper's DB does. Test in Task 3 (goldens include Pyramid).
5. **Status with no evidence.** A water whose rules have no resolvable season gives `unknown`/CHECK, never OPEN. Goldens include such a water in Task 2, asserted in Task 4.
